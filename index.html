Current research

INT8 accumulation on a two-read-port RISC-V core

My final-year project asks how a three-source DOT4ACC instruction can collect its operands and handle pipeline dependencies while retaining a two-read-port register file.

View current project →
  • Completed: RTL checks, a resident-layer workload comparison and OOC implementation timing checks
  • Current evidence: 10 image inputs, one convolution layer, compared with an existing DOT4+ADD baseline
  • Next: end-to-end model evaluation and validation on physical hardware

RISC-V INT8 dot-product extension

  • In progress
  • RTL simulation

Integrated fused INT8 dot-product accumulation into a five-stage RISC-V core with a two-read-port register file.

  • 10.26% fewer cycles for one complete convolution layer versus DOT4+ADD at 50 MHz
  • INT32 accumulators and INT8 outputs matched reference results across ten images

Two-stage CMOS op-amp

  • Post-layout simulation
  • LVS matched

Designed a two-stage CMOS amplifier and evaluated its parasitic-extracted layout in Cadence Virtuoso and Spectre.

  • Post-layout: 82.93 dB gain and 22.48 MHz UGBW at the typical corner, 3 pF load
  • LVS matched; remaining DRC spacing violations prevent full physical signoff
